# 图片挑选工具（Image Picker）

一个基于 **Python + PyQt5** 的桌面图片挑选工具，用于快速浏览、筛选、移动图片，并支持批量处理、缩放查看、拖拽平移等操作。

---

## 功能特性

- 📁 选择待处理图片文件夹与保存文件夹
- 🖼️ 中间区域显示当前图片，支持**滚轮以鼠标为焦点缩放**和**鼠标拖拽平移**
- ✂️ 一键把当前图片剪切到保存文件夹
- 🔁 支持把保存的图片剪切回待处理文件夹（单张 / 批量）
- 🗑️ 支持批量删除已保存图片
- 📋 左右两个列表实时显示待处理 / 已保存图片，标题显示数量统计
- 👆 点击左侧列表任意项可跳转到指定图片
- 🔍 双击右侧列表项弹出大图预览对话框
- ⌨️ 全局快捷键：空格剪切、左右方向键切换、R 移回、Delete 删除
- 📦 可打包为 Windows `.exe` 单文件程序

### 1. 主界面快捷键

| 快捷键 | 一句话功能 |
|---|---|
| `空格` | 剪切当前图片到保存文件夹 |
| `←` | 上一张 |
| `→` | 下一张 |
| `0` | 重置缩放 |
| `R` | 把右侧选中图片移回待处理文件夹 |
| `Delete` | 删除右侧选中图片 |

- Python 3.7 及以上

```bash
pip install PyQt5
pip install pyinstaller

# 文件打包
```
